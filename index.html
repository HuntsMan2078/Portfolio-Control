数据与设置

SQLite 本地数据库持仓、目标、历史快照和设置会保存到本机 Portfolio Control 数据库；浏览器存储仅作为故障缓存。
自动备份每次数据变更都会刷新当天的 JSON + SQLite 日备份，并自动保留最近 60 天。
跨设备云同步默认关闭。启用后 Windows / macOS 各自保留 SQLite，本地修改加密后同步到 Supabase；断网仍可使用。
自动行情范围股票：Longbridge CLI · 加密货币：Binance 公共行情 · 汇率：自动日度参考汇率 · 黄金：XAU/HKD 参考值；XGT Bank Buy 与实物回购价可手动覆盖。
备用汇率源归属：Rates By Exchange Rate API
